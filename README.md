# STAY ASLEEP — 2 枚の扉で、夢を深く

夢の中に浮かぶ 2 枚の扉のうち、夢が続くのは片方だけで、もう片方を開けると目が覚める。ただの運を、どこまで深く眠れたかと、その確率（10 枚で 1/1,024）で記録していく。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/stay-asleep/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 夢の中に扉が 2 枚。夢が続くのは、どちらか 1 枚だけ。
2. 選んで開ける（扉か、画面の左半分・右半分をタップ。PC は ← →）。夢が続けば、また 2 枚。目が覚めたら終わり。
3. どこまで深く眠れるか（深さ = ぬけた扉の数）。考えても分からない、ただの運。その運を記録する。

- 目が覚めたら「もう一度眠る」（Enter / Space でも）。
- **今日の扉**: 日付から並びが決まり、同じ日なら誰でも同じ並び。1 日 1 回だけで、途中で閉じても同じ深さから続く。
- **記録**: 自己ベスト・今日の最高・眠った回数・ぬけた扉の合計・平均の深さ・深さの分布（運がふつうならこのくらい、の線つき）。20 回眠ると「あなたの運」が出る。
- 扉を選んだ瞬間に結果を保存する。開くまでの間に閉じても、なかったことにはならない。

### 正解が先に決まっていることの確かめ方（封）

ふだんの扉は、眠りのはじめに 16 バイトの種（16 進 32 文字）を作り、その SHA-256 を「封」として扉の下に出す（先頭 16 文字）。
深さ i（0 から）の扉の正解は、`SHA-256(種 + ":" + floor(i / 256))` の `i % 256` ビット目（先頭のバイトの上のビットから。0 = 左、1 = 右）。
目が覚めたら「封を開ける」で種の全文と正解の並びが出る。手元でも確かめられる。

```sh
printf %s <種> | shasum -a 256    # 封と同じになる
# 深さ 0 から n 枚ぶんの正解
python3 -c "import hashlib,sys;s,n=sys.argv[1],int(sys.argv[2]);print(' '.join('左右'[hashlib.sha256(f'{s}:{i//256}'.encode()).digest()[i%256//8]>>(7-i%8)&1] for i in range(n)))" <種> <n>
```

今日の扉の種は `stay-asleep:YYYY-MM-DD`（端末の日付）。封はなく、日付が分かれば誰でも同じ並びを計算できる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 決まりの自己チェック（正解の出し方・封・今日の扉・偏り・確率の書き方・記録）
```

- `logic.js`: 決まり（種 → SHA-256 → 正解、確率の書き方、記録の計算）。画面に触らない。
- `main.js`: 描く・触る・鳴らす・保存する。音は Web Audio で作っている（音声ファイルなし）。
- 保存（localStorage）: `stay-asleep.settings`（音・はじめの説明）、`stay-asleep.stats`（ふだんの記録。`open` は途中の眠りで、閉じたら次に開いたときその深さで終わった扱い）、`stay-asleep.daily`（今日の扉の日ごとの深さと、今日の途中）。
